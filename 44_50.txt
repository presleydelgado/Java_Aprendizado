🔹 Dia 47 — Encontrar índice de um número

Objetivo: retorno mais inteligente

Enunciado:

método recebe:

int[] array

int valor

retorna:

posição (índice) onde o número aparece

ou -1 se não existir

Exemplo:
array {5,8,10}, buscar 8 → retorna 1
buscar 3 → retorna -1

Conceito MUITO importante:

retorno significativo

controle de fluxo

{1,-2,3} → false

Conceito:

validação

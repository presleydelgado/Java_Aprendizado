1 - Adicionar

5 - Função extra (ex: média, filtro, etc)
0 - Sair

👉 Esse é o mais importante da semana

🧠 Regras da semana (IMPORTANTE)
❌ NÃO fazer:
só métodos com print
código sem menu
código sem interação
✅ FAZER:
usar Scanner
usar while
usar switch
separar classes (como você já faz)
🔥 Dica de OURO (isso vai te ajudar MUITO)

Estrutura base do menu:

Scanner sc = new Scanner(System.in);
int opcao;

do {
    System.out.println("1 - ...");
    System.out.println("0 - Sair");

    opcao = sc.nextInt();

    switch(opcao){
        case 1:
            // ação
            break;
    }

} while(opcao != 0);

# Java Aprendizado

Repositório com exercícios diários de Java focados em lógica e orientação a objetos.

## Conteúdo

- Sistemas de cadastro (clientes, alunos, funcionários)
- Manipulação de listas (ArrayList)
- Regras de negócio (filtros, condições)
- Pequenos sistemas simulando cenários reais

## Tecnologias

- Java
- Git

## Objetivo

Praticar programação diariamente e evoluir para projetos mais completos.
